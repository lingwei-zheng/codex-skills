# Field Context Reference Pack

This directory is a non-triggering reference pack derived from NORA materials.
It is not an installed NORA skill.

Use these files from ARS, peer-review, nature-figure, or conceptual-figure-workflow
when a task needs geography, human geography, GIScience, GeoAI, spatial analysis,
environmental exposure, or health geography grounding.

Default language for Chinese notes and reports is Simplified Chinese unless the
user explicitly requests Traditional Chinese.

Use `geography-publication-readiness.md` for domain-specific contribution,
question-method-scale fit, theory-mechanism fit, argument progression, title
accuracy, and desk-reject risk checks.

These references provide domain checks, not an exploration policy. Use the
project's scientific protocol for research ambition and development decisions.

Use `geography-conceptual-figure-patterns.md` for defensible figure structures,
scale-aware semantic graphs, spatial-versus-causal distinctions, health
geography pathways, and GIScience inference pipelines.
