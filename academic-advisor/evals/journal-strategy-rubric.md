# Journal strategy behavioral evaluation

For material changes to journal recommendation rules, give an independent
agent `journal-strategy-cases.json`, the current academic-advisor skill, and
the supplied raw materials. Do not give it this rubric or implementation
history. Keep generated answers in an isolated task workspace, outside the
skill repository. These tasks require no network, live submissions, or real
experiments. Evaluate actual recommendations, not keyword presence.

| Case | Observable criteria |
|---|---|
| strong-specialist-result | Considers Alpha as a justified current first choice and Beta as a same-tier alternative; uses the supplied criteria and evidence. Does not impose global, causal, mechanistic, or extra-experiment prerequisites based on a regional/incremental label. Distinguishes preparation from optional enhancements. |
| early-development | Gives a conditional development route without inventing results or calling the plan submission-ready; current incompleteness does not erase a plausible Alpha route. |
| rejection-feedback | Uses actual scope feedback and leaves the unexplained rejection cause unknown. Provides a justified Alpha/Beta sequence without automatic downgrading after two rejections or an invented evidence deficit. |
| validity-defect | Does not convert the invalid main result into a publishable claim by changing venue or adding limitations. Prepares permitted diagnosis/repair work; does not rerun, submit, or report final readiness without the existing prerequisites. |
| user-constraints | Prioritizes Beta within the hard list and no-fee constraint. Does not confuse a submission deadline with acceptance timing, promise acceptance, or fabricate numerical odds. Explains confidence as fit-assessment confidence. |

Record case-level observations and any targeted correction/recheck. Passing
these finite samples is not a universal behavior guarantee. Preserve review
independence and existing authorization gates throughout.
