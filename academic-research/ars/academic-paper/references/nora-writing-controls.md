# NORA-Informed Writing Controls

Use these controls for paper outlining, drafting, revision tracking, and submission preparation. They supplement the existing ARS claim-intent and claim-reference audit; do not create a parallel claim-support schema.

## Advantage-Led Introduction And Title

Read `../../../../shared/advantage-led-research-narrative.md` and reuse the
current advantage/evidence record before fixing the Introduction.

Use problem -> specific gap -> core approach -> decisive finding -> significance.
The gap must follow from the reviewed evidence; use a bounded search statement
or precise account of existing evidence rather than inventing universal absence.
The proposed contribution must answer that same gap. A brief quantitative or
qualitative preview of the strongest supported result belongs in the contribution
paragraph; detailed result narration belongs in Results.

For a longer geography paper, six paragraphs are one optional expansion: problem,
domain context, relevant synthesis, precise gap, approach/contribution/evidence,
and an optional roadmap. Merge or omit rhetorical moves when the argument is
clear without them. No fixed paragraph count, roadmap, or exception record is
required; the user's structure and verified venue requirements take priority.

Do not create a standalone Literature Review merely because the paper uses
IMRaD. Add that section only when the user requests it or verified journal
instructions require it. Otherwise synthesize relevant literature in the
Introduction and Discussion.

State the contribution first; add a boundary where it changes interpretation.
The title should name the central contribution and useful searchable specifics,
with a scope and claim strength supported by the design. Avoid empty openers
such as "A study of"; do not impose a universal title length or claim type.

## Contribution Consistency

Assign each contribution a stable ID (`C1`, `C2`, ...). The outline must map every contribution to:

- the Introduction paragraph where it is promised;
- the Results or analysis section that supplies evidence;
- the Discussion section that interprets it;
- the Conclusion sentence that closes it.

Do not add a contribution in the Conclusion that was not established and evidenced earlier. If a contribution lacks a result or evidence location, mark it as a structural gap rather than drafting around it.

Add a leading-advantage row above the contribution map. Supporting
contributions must explain, establish, demonstrate, distinguish, or bound that
advantage rather than compete as unrelated novelties.

## Drafting Readiness

Select and report one mode before drafting:

| Mode | Use when | Allowed output |
|---|---|---|
| `full` | Main evidence, results, sources, and section inputs are available | Complete prose, subject to existing claim and citation audits |
| `partial` | Some sections are evidence-ready and others have material gaps | Draft only supported sections; leave explicit gap markers elsewhere |
| `skeleton` | The study is still an idea, plan, or evidence-poor outline | Structure, paragraph purposes, claim slots, and evidence requirements only |

Use `[MATERIAL GAP: ...]`, `[LITERATURE NEEDED: ...]`, or `[EVIDENCE NEEDED: ...]` for missing inputs. Never turn an unsupported slot into polished factual prose.

## Stable Revision IDs

Assign issue IDs by severity:

- `M1`, `M2`, ... for major or publication-blocking issues;
- `Mo1`, `Mo2`, ... for moderate issues;
- `m1`, `m2`, ... for minor or editorial issues.

Keep the same ID across rounds. Track each item as `NEW`, `CARRY-OVER`, `RESOLVED`, `DEFERRED`, or `DISAGREED`. New rounds may append IDs but must not renumber existing items.

## Submission Readiness Manifest

At final formatting, emit a concise manifest containing:

- source manuscript and target journal;
- journal-guideline source and verification date, when used;
- generated files and formats;
- unresolved citation, evidence, figure, table, disclosure, or formatting gaps;
- readiness status: `ready`, `partial`, or `blocked`.

Use `ready` only when no unresolved submission-blocking gap remains. Use `partial` for a usable package with disclosed non-blocking work outstanding. Use `blocked` when evidence, integrity, required files, or verified venue requirements are incomplete.
