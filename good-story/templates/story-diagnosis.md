# Story Diagnosis Template

```text
用 $good-story 帮我诊断这批材料里最强、也最站得住的论文故事。

研究领域：
目标期刊或目标读者：
已有材料：
[粘贴结果、图表、摘要、段落或要点]

我现在想讲的主线：

我最担心的问题：

请输出：
1. 故事状态：supported / candidate / blocked
2. 中心主张、核心张力、决定性转折和一句话复述
3. 5-7 步故事主线
4. 证据地图：主张 -> 证据位置 -> 证据强度 -> 边界或竞争解释
5. 修改目标：标题 / 摘要 / 图序 / 章节顺序及其证据依赖
6. 尚未解决的风险，以及后续步骤不得提出的主张
```
