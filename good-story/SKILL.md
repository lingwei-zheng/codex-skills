# Good Story

Organize evidence around a memorable scientific contribution. Persuasion must
preserve what the evidence supports. Use
`../shared/advantage-led-research-narrative.md` as the source of truth for
advantage-led framing, fair comparisons, materiality and revision invariants.
For scientific judgments, use the project-root
`SCIENTIFIC_EXPLORATION_PROTOCOL.md` under project `AGENTS.md`; no bundled
methodology fallback. If missing, identify the dependency without blocking
independent editing. Rephrasing an established claim needs no protocol loading.

## Source Depth Rule

Read the actual materials needed for the claim, including methods, results,
figures or supplements when decisive. Title/abstract-only input supports a
provisional framing, not a mature whole-paper diagnosis. Honor a bounded reading
scope and state its consequences; do not imply unread evidence was inspected.

## Workflow

1. Identify the question, audience, strongest supported contribution and decisive
   evidence. Distinguish observation, interpretation and speculation.
2. For an open story, compare a few plausible spines; for an established story,
   diagnose and edit it directly. Do not generate alternatives as a ritual.
3. Choose the fair task, comparator, metric and setting that reveal the value.
   An informative null or boundary can carry the story. Do not conceal evidence
   that overturns or narrows the central claim.
4. Organize the requested text or outline as problem -> gap -> approach ->
   decisive evidence -> consequence. Order Results by argument, not lab history.
   Give each prominent analysis/figure a job: establish, explain, demonstrate,
   distinguish or bound the contribution.
5. Check that results answer the stated gap, claim strength matches evidence,
   and a reader can retell the contribution. Include material conditions where
   needed. Do not append a generic weakness inventory.

## Scale the Deliverable

For a local rewrite, return self-contained text. Explain changes when requested
or needed to understand scientific meaning, use, validation status or a pending
decision. For a full story diagnosis, provide the leading advantage, fair arena,
one-paragraph story, short spine, evidence/job map and relevant rewrite targets.

Use `references/handoff-contract.md` when another workflow or later work block
will consume the diagnosis. Preserve its `supported`, `candidate` or `blocked`
story status, evidence locators and downstream claim boundaries; reuse the
existing outline/record. A story status grants no execution approval.
Do not require a full handoff card for a one-off paragraph edit.

Rank alternate stories only when the direction is open. Add a material
constraint only when it changes the claim, route or required reporting;
reviewer-resistance analysis is for an explicit request or a decision-changing
defect. Preserve scientific truth before claim calibration, argument and style.
